1. Aim: To place eight queens on an 8×8 chessboard so that no two queens attack each other, using Backtracking Search.

2. Objectives
	1. To understand the 8-Queens problem as a CSP.
	2. To understand the Backtracking technique.
	3. To check safe positions of queens.
	4. To find all possible solutions.
	5. To count safety checks and backtracking steps.

3. Theory
The 8-Queens problem means placing 8 queens on an 8×8 chessboard.

Rules:
- No two queens should be in the same row.
- No two queens should be in the same column.
- No two queens should be on the same diagonal.
Backtracking: Backtracking is a search technique. It places a queen in a safe position. If the next queen cannot be placed safely, it goes back and tries another position.

CSP: CSP stands for Constraint Satisfaction Problem. It means finding a solution by following given conditions.

4. Algorithm
	1. Start.
	2. Create an empty chessboard.
	3. Place the first queen in a safe position.
	4. Check whether the next queen can be placed safely.
	5. If the position is safe, place the queen.	
	6. If the position is not safe, try another column.
	7. If no safe position is available, go back to the previous row.
	8. Repeat until all 8 queens are placed.
	9. Display all solutions and statistics.
	10. Stop.

5. Python Program


N = 8

def is_safe(board, row, col):
    for r in range(row):
        c = board[r]

        if c == col or abs(c - col) == abs(r - row):
            return False

    return True


def solve(board, row, solutions, stats):
    if row == N:
        solutions.append(board[:])
        return

    for col in range(N):
        stats["checks"] += 1

        if is_safe(board, row, col):
            board[row] = col

            solve(board, row + 1, solutions, stats)

            board[row] = -1
            stats["backtracks"] += 1


def print_board(board):
    for r in range(N):
        print(" ".join("Q" if board[r] == c else "." for c in range(N)))
    print()


solutions = []
stats = {"checks": 0, "backtracks": 0}

solve([-1] * N, 0, solutions, stats)

print("Total solutions found:", len(solutions))

if not solutions:
    print("No solution exists for N =", N)

else:
    print("First solution:", [c + 1 for c in solutions[0]],
          "(column number of queen in each row)\n")

    print_board(solutions[0])

    if len(solutions) > 1:
        print("Second solution:", [c + 1 for c in solutions[1]], "\n")
        print_board(solutions[1])

    print("Safety checks performed:", stats["checks"])
    print("Backtracking steps     :", stats["backtracks"])

6. Conclusion:

The 8-Queens problem was successfully solved using Backtracking Search. The program found 92 possible solutions. It checks the safe position of each queen and uses backtracking when a position is not suitable.
